# Student Management System

A Java-based Student Management System built using Java, Maven, MySQL, and JDBC.

## Features
- Add student records
- View student records
- Update student details
- Delete student records

## Technologies Used
- Java 17
- Maven
- MySQL
- JDBC

## Database
The project uses MySQL to store student information, including name, email, course, and age.

## How to Run
1. Install Java 17 and MySQL.
2. Create the database using `database.sql`.
3. Configure the database credentials in `DBConnection.java`.
4. Build the project using Maven.
5. Run `Main.java`.
